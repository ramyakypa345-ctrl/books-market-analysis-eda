# 📚 Books Market Analysis using Web Scraping & Exploratory Data Analysis (EDA)

## 📖 Project Overview

This project demonstrates an end-to-end Data Analytics workflow by collecting book data from the **Books to Scrape** website using Web Scraping techniques. The collected data was cleaned, transformed, analyzed, and visualized to generate meaningful business insights that support data-driven decision-making.

This project showcases practical skills in **Web Scraping, Data Cleaning, Exploratory Data Analysis (EDA), Data Visualization, and Business Analytics** using Python.

---

## 🎯 Project Objectives

- Collect book information through Web Scraping.
- Clean and preprocess the collected dataset.
- Analyze book prices, ratings, and categories.
- Identify trends and patterns using Exploratory Data Analysis.
- Generate actionable business insights and recommendations.

## 🧹 Data Cleaning

The following preprocessing steps were performed:

- Removed duplicate records
- Checked and handled missing values
- Converted price values into numeric format
- Converted star ratings into numerical values (1–5)
- Standardized column names
- Extracted category information
- Prepared a clean dataset for analysis

## 💡 Key Business Insights

- Most books belong to Mid-Range and Premium price categories.
- Higher prices do not guarantee better customer ratings.
- Suspense books have the highest average price.
- Highly rated books are available across all price categories.
- Customers value quality and content more than price.

---

## 📢 Business Recommendations

- Increase inventory for highly rated categories.
- Promote affordable books with high ratings.
- Offer discounts on expensive books with lower ratings.
- Bundle books from popular categories.
- Focus marketing campaigns on highly rated genres.
