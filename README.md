# 📚 Books Market Analysis using Web Scraping & Exploratory Data Analysis (EDA)

## 📖 Project Overview

This project demonstrates an end-to-end data analytics workflow by scraping book data from the **Books to Scrape** website, cleaning and transforming the dataset, performing Exploratory Data Analysis (EDA), generating business insights, and visualizing key trends.

The project showcases practical skills in **Web Scraping, Data Cleaning, Feature Engineering, Data Visualization, and Business Analysis** using Python.

**Data Source:** https://books.toscrape.com/

> **Note:** Books to Scrape is a demo website created for practicing web scraping and data analysis.

---

## 🎯 Project Objectives

- Scrape book information from multiple pages.
- Clean and preprocess the collected dataset.
- Perform Exploratory Data Analysis (EDA).
- Engineer useful features for analysis.
- Generate business insights and recommendations.
- Visualize important trends using charts.
- Export cleaned datasets and analysis reports.

## 📊 Dataset Description

The dataset contains information collected from **Books to Scrape**, including:

- Book Title
- Price
- Rating
- Availability
- Category
- Product URL

---

## 🧹 Data Cleaning

The dataset was cleaned by:

- Removing duplicate records
- Handling missing values
- Converting prices into numeric format
- Transforming ratings into numerical values
- Standardizing data types
- Cleaning text columns

---

## ⚙️ Feature Engineering

Additional features were created to improve analysis:

- Price Category (Budget, Mid-Range, Premium)
- Rating Category
- Title Word Count
- Price per Rating
